# 畅言论坛 — 项目介绍

> **畅言论坛** (CA for Android) 是一款面向校园场景的公告论坛 Android 应用，  
> 以精致的紫粉渐变 UI 和毛玻璃视觉风格，为用户提供公告浏览、动态发布、工具分享等一站式校园信息交流平台。

---

## 核心亮点

### 离线优先，零成本运行

所有数据存储在设备本地 SQLite 数据库中，无需后端服务器，无需网络连接，零运维成本。打开即用，随时随地。

### 精致 UI 设计

- **紫粉渐变背景**: 135 度线性渐变，从淡紫到淡粉，营造柔和温暖的视觉氛围
- **毛玻璃/亚克力效果**: 原生实现的半透明卡片和弹窗，无任何第三方库依赖
- **胶囊形浮动导航**: 底部导航栏采用圆角胶囊造型，悬浮于页面之上
- **流畅动画**: 页面右滑进入、弹窗上下滑入、FAB 缩放等丰富的过渡动画

### 轻量级架构

纯 Java 开发，仅依赖 AndroidX 核心库和 Material Design 3，无重量级框架，APK 体积小巧。

### 功能完整

涵盖发帖、回复、搜索、收藏、通知、匿名发布、图片上传、头像管理、夜间模式等完整功能链。

## 交互流程

### 登录注册

```
首次打开应用 → 点击"去登录" → 跳转登录页
  → 输入用户名和密码 → 本地数据库校验
  → 登录成功 → 保存登录状态 → 返回主页

新用户 → 点击"去注册" → 输入用户名、密码、确认密码
  → 校验通过 → 写入数据库 → 自动登录 → 返回主页
```

### 发帖回复

```
浏览帖子列表 → 点击右下角 FAB 按钮 → 弹出发帖弹窗
  → 输入标题和内容 → (可选) 开启匿名 / 选择图片
  → 点击发布 → 数据保存到本地 → 自动刷新列表

浏览帖子列表 → 点击帖子 → 进入详情页
  → 底部输入框输入回复 → 点击发送
  → 回复保存 → 列表刷新 → 滚动到底部
  → (若回复他人) 自动发送通知
```

### 收藏通知

```
帖子详情页 → 点击收藏按钮 → 切换收藏状态
  → 金色星星 = 已收藏 / 紫色星星 = 未收藏

个人中心 → 点击"我的收藏" → 查看收藏列表
个人中心 → 点击"消息通知" → 查看通知列表
  → 点击通知 → 标记已读 + 跳转帖子详情
  → 点击"全部已读" → 一键标记所有通知为已读
```

## 设计特色

### 视觉风格

| 元素 | 设计细节 |
|------|----------|
| 背景 | 135 度线性渐变: 淡紫 (#E8D5F5) 到淡粉 (#FFDAE8) |
| 卡片 | 60% 白色半透明 + 20dp 圆角 |
| 导航栏 | 胶囊形浮动底栏，28dp 圆角 |
| FAB | 蓝紫到粉色渐变 (#7B68EE 到 #B06AB3) |
| 按钮 | 16dp 圆角 + 毛玻璃效果 |

### 日间 / 夜间双主题

| 模式 | 背景 | 卡片 | 文字 |
|------|------|------|------|
| 日间 | 淡紫→淡粉渐变 | 60% 白色 | 深色 |
| 夜间 | 深紫→深粉紫渐变 | 44% 白色 | 浅灰 (#E0E0E0) |

使用 Android 原生 `AppCompatDelegate` 实现，设置通过 SharedPreferences 持久化，重启应用后保持用户偏好。

### 页面过渡动画

- **进入详情/收藏/通知**: 右滑进入 + 淡出退出
- **弹窗出现**: 下方滑入
- **弹窗关闭**: 下方滑出
- **列表项入场**: 渐变动画

## 技术优势

| 优势 | 说明 |
|------|------|
| **零服务器成本** | 完全本地化存储，无需部署和维护后端服务 |
| **离线可用** | 无网络依赖，任何环境下均可正常使用 |
| **极小体积** | 仅依赖 AndroidX 核心库，无第三方重量级框架 |
| **原生毛玻璃** | BlurUtil 原生实现，无需引入模糊效果第三方库 |
| **数据库索引** | 帖子表、回复表均有索引优化，列表加载流畅 |
| **事务安全** | 回复的增删操作使用数据库事务，保证 reply_count 一致性 |
| **版本迁移** | SQLiteOpenHelper 版本迁移机制，升级不丢数据 |

## 适用场景

### 校园公告

学校或学院发布公告通知，学生浏览查看并回复讨论。适用于课程安排、活动通知、政策公告等场景。

### 社团动态

学生社团发布活动动态，支持匿名发言鼓励自由表达。适用于社团招新、活动回顾、意见征集等场景。

### 工具分享

学生分享和发现实用工具，如学习资料、软件推荐、校园服务等，支持快速搜索定位。
